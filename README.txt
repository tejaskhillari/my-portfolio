HOW TO RUN
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. If you have Live Server installed, right-click index.html and choose "Open with Live Server".
   Or double-click index.html to open it in your browser.
4. Internet is needed for Bootstrap, Font Awesome, Google Fonts, and jQuery CDNs.
